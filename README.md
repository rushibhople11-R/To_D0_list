# To_D0_list

This repository contains a simple task list for planning and tracking work.

## Files

- `TODO.md` — a markdown task list organized by Today, In Progress, This Week, and Later.
- `TODO.html` — the same task list rendered as an HTML page for easy viewing.

## Usage

Open `TODO.md` to update tasks directly in markdown, or open `TODO.html` in a browser for a quick visual view.
